# 📜 Privacy Policy Classification using Long-Context LLMs
## 📖 Overview

This project implements an automated pipeline for analyzing and classifying Privacy Policies based on the **C3PA Taxonomy**. By leveraging Large Language Models (LLMs) with **long-context windows**, the system extracts data practices, categories, and attributes from complex legal texts.

The core innovation of this project lies in its **robust evaluation strategy**, designed to handle the discrepancy between verbose human annotations (C3PA dataset) and concise LLM extractions, employing AI-as-a-judge methodologies for nuanced equivalence checking.

## 🚀 Key Features

* **⚡ Multi-Model Support:** Integrated with OpenAI, Google Gemini, and OpenRouter for flexible model selection.
* **🧠 Dynamic Prompting:** Injects taxonomy definitions from `config.py` directly into the system prompt, allowing the LLM to act as a "trained expert" rather than guessing labels.
* **⚖️ Advanced Evaluation Logic:** 
    * Implements strict token-based F1 scoring for deterministic matches.
    * Features an `AIEvaluator` using `DeepEval` to perform qualitative, reasoning-based equivalence checks when exact matches fail, significantly improving recall accuracy by understanding semantic similarity.
* **📊 Comprehensive Visualization:** Automatically generates side-by-side HTML reports comparing Ground Truth vs. Prediction for qualitative analysis, including the reasoning generated by the AI judge.
* **📈 Automated Benchmarking:** Includes scripts to aggregate results, compute metrics (Precision, Recall, F1), and generate summary reports and plots suitable for publication or analysis.

## 🛠️ Installation & Setup

This project uses `uv` for fast package management.

### Prerequisites

* Python 3.10+
* API Keys for OpenAI, Google Gemini, OpenRouter, or DeepEval (if using cloud features).

### 1. Clone the repository

```bash
git clone https://github.com/zhovka02/FullPPClassification.git
cd FullPPClassification
```

### 2. Install dependencies

**Using uv (Recommended):**

```bash
uv sync
```

**Using pip:**

```bash
pip install -r requirements.txt
```

### 3. Environment Variables

Ensure you have the necessary environment variables set for your chosen LLM providers. You can export them in your shell or use a `.env` file if you have python-dotenv configured.

```env
OPENAI_API_KEY=sk-...
GOOGLE_API_KEY=...
OPENROUTER_API_KEY=...
```

## 💻 Usage

### Running the Pipeline

To run the full pipeline (Annotation -> Evaluation -> Visualization) across multiple models, execute `main.py`. You can configure the specific models to test within the `main.py` script.

```bash
python main.py
```

### Generating Summary Reports

After running the benchmarks, you can generate an averaged summary report and corresponding plots using `result_averager.py`.

```bash
python src/result_averager.py
```

This will output `benchmark_average_report.html` and various PNG plots in the `plots/` directory.

## 🏛️ Code Structure Details

*   **`annotator.py`**: Constructs prompts and calls the LLM to extract policy segments.
*   **`ai_evaluator.py`**: Uses DeepEval to compare LLM predictions against ground truth semantically, providing reasoning for matches or mismatches.
*   **`evaluator.py`**: Computes standard token-based F1 scores.
*   **`visualizer.py`**: Creates the HTML reports found in the `reports/` folder, color-coding exact matches, substring matches, AI-judged matches, and misses.
